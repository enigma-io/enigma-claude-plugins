# Contributing

Thanks for your interest in improving this marketplace.

This repository is a generated public mirror of Enigma's internal Claude Code marketplace. That means:

- pull requests here are welcome for discussion and review
- the canonical source of truth lives in Enigma's internal repository
- accepted changes are applied internally first, then republished here
- direct-only changes in this repo may be overwritten by the next publish

## If you want to propose a change

You can open:
- a GitHub issue, or
- a pull request describing the desired change

If we decide to take the change, a maintainer will port it into the internal source repository and publish an updated mirror back to GitHub.

## What to expect

- We may keep public PRs open while we evaluate them.
- We may reference an internal commit or release when the change is published.
- We may close PRs after the mirrored update has been published.

Thanks for understanding.
